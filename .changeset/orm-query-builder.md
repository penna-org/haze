ThinkPHP (think-orm) feature parity for the ORM. Transactions: manual `Db.startTrans()` / `commit()` / `rollback()`, isolation levels and other options, `Db.inTransaction()`, `Model.transaction()` and row locks with `lock()`. Query builder: joins and aliases, subqueries in `whereIn` / `where` / `whereExists`, `group` / `having` / `distinct`, `union`, JSON paths (`meta->city`), time conditions (`whereTime`, `whereDay`, `whereMonth`, `whereYear`, `whereBetweenTime`…), `whereColumn` / `whereRaw` / `whereExp` / `whereNot` / `whereFindInSet` / `whereJsonContains`, `orderRaw` / `orderField` / `orderRand`, `withoutField` / `fieldRaw`, `insertIgnore` / `upsert` / `replace` / `selectInsert`, `inc` / `dec` / `exp` / `data`, `cursor()` and `paginateX()`, keyed `column()`, query caching with `cache()` and `removeOption()`. Models: global scopes, searchers (`withSearch`), read-only fields, optimistic locking, `allowField` / `force` / `inc`, static `update` / `saveAll` / `destroy(condition)` / `findOrEmpty`, cancellable before events and per-instance or per-query `hidden` / `visible` / `append` / `withAttr`. Relations: `belongsToMany` with pivot data and `attach` / `detach` / `sync`, `hasManyThrough` / `hasOneThrough`, `morphOne` / `morphMany` / `morphTo`, eager loading constraints, `withCount` / `withSum` / `withAvg` / `withMax` / `withMin`, `has` / `hasWhere` / `hasNot`, writes through relations, `bind()` and `withDefault()`.
