# create-hazejs

Create a new hazejs project.

## Usage

```bash
pnpm create hazejs my-app            # interactive
pnpm create hazejs my-app -t api     # backend-only API
pnpm create hazejs my-app -t vue     # Vue 3 full-stack
pnpm create hazejs my-app -t react   # React 19 full-stack
pnpm create hazejs my-module -t module  # publishable module package (routes, config, migrations)
pnpm create hazejs my-app --auto-import # turn on auto imports (@hazejs/auto-import)
```

Part of [hazejs](https://github.com/penna-org/haze) — see the main README for documentation.
